# Examples

Example flows that show how to use your nodes.

Node-RED lists every `.json` file in this folder under **Import → Examples**,
using the file name as the title. Subfolders become groups in that menu.

To add an example:

1. Build the flow in Node-RED.
2. Select its nodes, then choose **Export** and copy the JSON.
3. Save it here as `<short-name>.json`, for example `basic-usage.json`.

This folder is included in the published npm package.
